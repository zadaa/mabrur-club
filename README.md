# Mabrur.club - Website Resmi Amanat IPHI

Portal resmi **Mabrur.club** di bawah amanat Pengurus Pusat **Ikatan Persaudaraan Haji Indonesia (IPHI)**. Platform ini menghubungkan jamaah alumni haji dan pra-haji Indonesia dalam wadah ukhuwah, pembinaan ibadah, kemandirian ekonomi syariah, dan layanan keanggotaan terpadu (KTA Digital).

---

## 🕋 Identitas & Filosofi Desain
- **Background:** White & Off-White (`#FFFFFF` / `#F8F9FA`) — Bersih, luas, suci, ramah dibaca untuk semua usia.
- **Aksen Utama:** Ka'bah Obsidian Black (`#141416`) — Keteguhan dan keistiqomahan ibadah.
- **Aksen Kemuliaan:** Noble Warm Gold (`#D4AF37`) — Lambang kemuliaan kiswah, persatuan, dan kehormatan.
- **Aksen Penyeimbang:** Mosque Emerald Green (`#0D6843`) — Kesejahteraan dan kemakmuran lahir-batin umat.

---

## 📂 Struktur Halaman
1. **`index.html`** - Flagship Landing Page (Hero banner dengan foto Masjidil Haram berlatar blur, profil amanat Ketum Dr. Ir. H. Erman Suparno, 6 pilar kontribusi keumatan, showcase Apps Mabrur.club, 4 langkah alur keanggotaan, dan kontak sekretariat).
2. **`profil.html`** - Sejarah berdirinya IPHI sejak 1990 & ORPEHA 1980, 3 motivasi kelahiran, visi & misi, filosofi 7 elemen lambang IPHI, dan sayap badan pelaksana.
3. **`legalitas.html`** - Dokumen keabsahan hukum resmi berketetapan tetap (SK Menkumham RI No. AHU-0000881, Putusan Kasasi Inkrah Mahkamah Agung RI No. 480 K/TUN/2022 jo PTUN Jakarta, SK Pencabutan AHU 911 No. AHU.AH.01.43-2, Sertifikat Merek IPHI Kelas 41 IDM000993315, serta Hak Cipta Logo, Mars, dan Hymne).
4. **`struktur.html`** - Komposisi Dewan Kehormatan (Jenderal TNI Purn Try Sutrisno, Dudung Abdurachman, Sandiaga Uno, Ganjar Pranowo), Dewan Penasehat (Dr. Fadli Zon), Dewan Pakar (Prof. Dr. Ir. Muhammad Nuh, Prof. Dr. KH. Nasaruddin Umar), Pengurus Harian Pusat, dan hierarki ke 34 Pengurus Wilayah.
5. **`daftar.html`** - Pusat pendaftaran dwi-kanal (unduh aplikasi via Google Play/App Store atau pendaftaran online langsung dengan generator preview KTA Digital dinamis).

---

## 🚀 Cara Menjalankan
Cukup buka berkas `index.html` menggunakan browser modern (Chrome, Edge, Firefox, Safari) atau gunakan live server:
```bash
# Menggunakan PowerShell
Start-Process index.html

# Atau menggunakan Python HTTP Server
python -m http.server 8000
```
